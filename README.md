# Ceo.ooou.uz

Personal site of **Sarvarbek Sharipboyev**, founder of [ooou.uz](https://ooou.uz) and a full-stack, QA and AI engineer building **Bahola (SmartQR)** and **Voxly AI**.

## Sections
Hero · About (+ recruiter card) · Experience timeline · Bahola case study · Voxly AI (sign language) · Hackathons, certifications, awards & events · Projects · Contact

## Stack
Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4. Motion is plain CSS + IntersectionObserver and respects `prefers-reduced-motion`.

## Editing content
All text lives in [`src/data/profile.ts`](src/data/profile.ts): experience, certifications, awards, hackathons, events and projects.

## Run locally
```bash
npm install
npm run dev
```
